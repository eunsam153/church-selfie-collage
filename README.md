# 42 · 함께 만드는 교회 — square-cell update

## 이번 버전에서 수정한 내용
- 사용자가 제공한 `Artboard 6@4x(2).png`를 실제 가이드 원본으로 사용합니다.
- 가이드 이미지의 6열 × 7행(42칸) 그리드를 기준으로 번호별 가이드를 자릅니다.
- 촬영 화면을 1:1 정방형으로 표시합니다.
- 셔터를 누를 때 카메라 프레임 중앙을 정방형으로 크롭해 저장합니다.
- 빨간 가이드는 촬영 화면에만 겹쳐 보이며, 저장된 셀카에는 포함되지 않습니다.
- 최종 작품은 6×7 그리드의 정사각형 칸을 빈틈없이 채웁니다. 사진은 회전하지 않습니다.
- Supabase 테이블/Storage 연동은 기존 설정을 유지합니다.

## GitHub에 업데이트
기존 저장소의 파일을 이 ZIP 안의 파일로 교체해 주세요. `guide-template.png`와 `guide-overlay.png`도 반드시 `index.html`, `app.js`와 같은 폴더에 올려야 합니다. Supabase SQL은 다시 실행할 필요가 없습니다.

## 중요
- `guide-template.png`는 사용자가 제공한 원본 가이드 이미지입니다.
- 가이드 그리드 크롭은 이미지 내 검은색 그리드 경계를 기준으로 잡았습니다.
- 사진은 번호순으로 좌→우, 위→아래 배치됩니다.
- 브라우저 카메라를 사용하려면 HTTPS가 필요합니다.
- 저장된 기존 사진이 직사각형이어도 최종 결과에서는 중앙을 정방형으로 크롭해 칸에 맞춥니다.
- 기존 Supabase 정책은 프로젝트 참여자에게 읽기/쓰기 권한을 허용하는 공유 MVP용 정책입니다. 비공개/민감한 사진은 저장하지 마세요.
