# 42 · 함께 만드는 교회 — 스마트폰 웹 앱 MVP

스마트폰 브라우저에서 42개 선분을 선택하고, 현재 선분을 참고해 포즈를 잡은 뒤 셀카를 저장하는 프로토타입입니다. 사진은 번호별로 연결되며, 42개 슬롯이 모이면 같은 캔버스에서 콜라주를 미리 보고 PNG로 저장할 수 있습니다.

## 파일
- `index.html`: 앱 화면
- `styles.css`: 모바일 우선 스타일
- `app.js`: 카메라, 촬영/재촬영, 42개 슬롯, 합성 및 Supabase 연동
- `supabase-schema.sql`: 데이터베이스 및 Storage 정책
- `manifest.webmanifest`: 홈 화면 추가용 기본 설정

## 1. Supabase 설정
1. Supabase 프로젝트를 만듭니다.
2. Authentication 설정에서 **Anonymous Sign-ins**를 활성화합니다.
3. SQL Editor에서 `supabase-schema.sql` 전체를 실행합니다.
4. Project Settings > API에서 Project URL과 anon/public key를 확인합니다.
5. 앱의 ⚙ 설정에 URL, 공개 키, 작품 코드를 입력해 연결합니다.

> `service_role` / secret key는 절대로 웹 앱에 입력하거나 배포하지 마세요. 공개 키만 사용하고, 접근은 RLS 정책으로 제어합니다.

## 2. 스마트폰에서 실행
카메라 권한을 위해 HTTPS로 배포해야 합니다. 가장 쉬운 방법은 GitHub 저장소에 이 폴더의 파일을 올리고, Netlify 또는 Vercel 같은 정적 호스팅에 연결하는 것입니다. GitHub Pages에서도 HTTPS로 제공할 수 있습니다.

## 3. 현재 MVP의 한계 — 꼭 확인
- 선분 좌표는 첨부한 레퍼런스의 42개 빨간 선을 바탕으로 만든 **초기 근사 템플릿**입니다. 실제 행사 전에 원본 아트보드와 대조해 42개 좌표를 정확하게 보정해야 합니다.
- 현재 촬영 가이드는 요청대로 **선분 하나만 크게 표시**합니다. 카메라 화면에는 손의 실제 위치를 자동 인식하거나 포즈가 맞는지 판정하는 AI 기능은 없습니다.
- 사진은 번호별로 저장됩니다. 여러 사람이 동시에 같은 번호를 촬영하면 마지막 저장 사진으로 덮어쓸 수 있으니, 참가자마다 번호를 배정하는 방식이 안전합니다.
- 로그인은 익명 인증입니다. 링크를 가진 사람이 참여할 수 있고, 프로젝트 사진은 인증된 참여자에게 공유됩니다. 민감한 사진은 올리지 마세요.
- 기본 합성은 선분 중심에 사진을 회전·크롭하는 1차 구현입니다. 실제 레퍼런스처럼 각 셀카가 정확한 빨간 띠 모양을 채우도록 하려면, 원본의 각 선분 영역을 마스크로 따는 후속 보정이 필요합니다.
- 온라인 연결 전 임시 사진은 브라우저 IndexedDB에 저장됩니다. 브라우저 데이터를 지우면 임시 사진이 삭제될 수 있으므로, 여러 기기에서 쓸 때는 Supabase 연결을 사용하세요.

## 4. 다음 개발 단계
1. 원본 이미지 기준 42개 선분 좌표 정밀화
2. 각 선분의 폭·마스크를 적용해 사진이 가이드 띠 안에만 보이도록 합성
3. 참가자 번호 배정 링크 / 관리자 진행 현황
4. 결과물 해상도, 여백, 성경 구절, 배경 등 작품 출력 설정
